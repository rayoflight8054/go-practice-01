## Запуск первой программы

Откройте терминал в папке проекта, где находятся `main.go` и `go.mod`.

```text
go run .
```

Карточка проекта:
```text
go run ./cmd/card
```

Эксперименты с переменными:
```text
go run ./cmd/experiments
```

Конвертер:
```text
go run ./cmd/time-converter
```

## Проверка сборки и оформления

```text
go fmt ./...
go build ./...
```
