## Запуск первой программы

Откройте терминал в папке проекта, где находятся `main.go` и `go.mod`.

```text
go run .
```

Карточка проекта:
```text
go run ./cmd/card
```

Эксперименты с переменными:
```text
go run ./cmd/experiments
```

Конвертер:
```text
go run ./cmd/time-converter
```

Знакомство с условиями, циклами, функциями и коллекциями:
```text
go run ./cmd/task-summary
```

Знакомство со структурами, методами и указателями:
```text
go run ./cmd/task-model
```

Работа с интерфейсами и ошибками:
```text
go run ./cmd/task-cli
```
